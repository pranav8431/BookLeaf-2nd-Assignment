# Learning Bubble with this app

Bubble is a visual app builder: you design pages, define a database, and wire up behaviour with workflows, all without writing code. This folder teaches the parts this app uses, in the order they depend on each other.

| Lesson | You'll understand |
|---|---|
| [01 – Data and privacy](01-data-and-privacy.md) | Data types, fields, option sets, and privacy rules |
| [02 – Pages, elements and expressions](02-pages-elements-expressions.md) | How a page shows data, repeating groups, reusable elements, dynamic expressions |
| [03 – Workflows and states](03-workflows-and-states.md) | Events, actions, custom states, conditions, the login/sign-up flow |
| [04 – Talking to other systems](04-api-connector-and-limits.md) | API Connector, backend workflows, and what the Free plan allows |
| [Exercises](exercises.md) | Small, safe changes to try in the editor |

**Open the editor:** bubble.io → your app *pranavkr1503* → the editor opens on the `index` page. The tabs on the left are **Design** (pages), **Workflow**, **Data**, **Styles**, **Plugins** and **Settings**.

**Preview:** the *Preview* button opens `version-test`, the development version that uses the test database. Your three logins work there.

**Official material, if you want more:**

- Bubble Manual: https://manual.bubble.io (reference for every element and action)
- Bubble Academy: https://bubble.io/academy (short video courses; start with "Introduction to Bubble")

**Safety:** you're on the Free plan with a single development version, so every edit is live in `version-test` straight away. Before an experiment, note what you change, or use the editor's undo (Ctrl+Z). Don't rename fields: the n8n payload uses their names.
